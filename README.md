# Embedded C Fundamentals

A structured learning repository for building strong **C and Embedded C fundamentals** required for embedded systems and automotive embedded engineering.

This repository documents the programming concepts, problem-solving skills, and firmware-oriented C knowledge developed throughout my embedded engineering roadmap.

---

## Purpose

The purpose of this repository is to build the programming foundation required to:

- Understand C programming fundamentals
- Write clear and reliable Embedded C code
- Work with memory, pointers, structures, and bit manipulation
- Understand how C interacts with microcontrollers
- Develop firmware-oriented problem-solving skills
- Understand the programming concepts required for embedded drivers and firmware
- Prepare for embedded systems and automotive embedded engineering roles

# Phase 1 — Embedded C Foundation

Phase 1 establishes the fundamental C programming knowledge required before moving into deeper embedded firmware development.

Major areas include:

- C fundamentals
- Data types
- Variables
- Operators
- Bitwise operations
- Functions
- Arrays
- Strings
- Memory basics
- Pointers
- Structures
- Nested structures
- Enumerations
- Storage classes
- Preprocessor concepts
- Header files
- Bit manipulation
- Embedded C problem solving
- Embedded C interview preparation

Phase 1 is focused on **building a strong foundation**, not advanced firmware development.

---

# Phase 2 — Embedded Engineering Depth

Phase 2 builds on the Phase 1 foundation and moves toward practical firmware engineering.

Relevant Embedded C / firmware areas include:

- Register-level programming concepts
- Interrupt-related firmware design
- State-machine design
- UART driver structure
- SPI driver structure
- I2C driver structure
- Embedded firmware architecture
- Header/source organisation
- Modular driver design
- Hardware abstraction concepts
- State-machine based firmware
- Driver and application interaction

The main microcontroller and peripheral documentation is maintained in:

- `microcontroller-fundamentals`
